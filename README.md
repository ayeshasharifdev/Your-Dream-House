# Your Dream House

A responsive real estate website project designed to present residential properties in a clean and professional layout.

## 📌 About the Project

**Your Dream House** is a frontend web development project created to practice building a modern real estate website using HTML and CSS.

The website focuses on presenting houses and project information in an organized and user-friendly design.

## ✨ Features

* Responsive website layout
* Clean and simple user interface
* Property/project sections
* Image-based property presentation
* Structured HTML layout
* Custom CSS styling
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
